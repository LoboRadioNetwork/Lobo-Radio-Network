🗺️ THE TEXAS STRING — WHAT'S NEXT

Dallas is bead number one. Our transit engine reads the same kind of schedule data that transit systems all over Texas publish — so the same app, dressed in each city's own colors, is headed down the line:

Austin · Houston · San Antonio · El Paso · Fort Worth · Corpus Christi · Denton

…and beyond them, some thirty more Texas cities run buses on printed schedules our engine can read. One city at a time, each one checked stop-by-stop before it ships — the same way Dallas was. When a new city app lands, it will hang on this page.
